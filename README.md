# ToDo List Web Application
A simple yet functional ToDo List Web App built with HTML, CSS, JavaScript, Bootstrap, PHP, and MySQL.

This project demonstrates CRUD operations and task management with status tracking.
✨ Features
- Add new tasks with a chosen status (Created, Ongoing, On-Hold, Completed, Cancelled, Overdue).
- Display tasks dynamically from the database using JavaScript fetch API.
- Store tasks and statuses in a MySQL database (todos table).
- Responsive UI styled with Bootstrap.
- Automatic timestamp tracking (created_at, updated_at).

🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript and Bootstrap
- Backend: PHP (API endpoints)
- Database: MySQL

🚀 Getting Started
- Clone the repository - https://github.com/abandes08/todo_app.git
- Import the provided database schema (todo_db).
- Configure your PHP backend.
- Open index.html in your browser to start managing tasks.
